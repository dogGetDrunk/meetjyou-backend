# AT-3-1: 삭제 결과 판정 — 404는 성공, 그 외 실패는 false

- 요구사항: REQ-3 (D2)
- Given/When/Then:
  - `objectStorageClient.deleteObject`가 `BmcException(404, ...)` → `OracleObjectStorageService.deleteObject` = true
  - `BmcException(500, ...)` 등 그 외 예외 → false (기존 테스트 유지)
  - `UserImgService.deleteUserProfileImg`: 원본·썸네일 둘 다 true → true, 하나라도 false → false, 하나가 실패해도 나머지 삭제 시도는 수행
- 보호 대상 테스트 파일: src/test/java/com/dogGetDrunk/meetjyou/cloud/oracle/OracleObjectStorageServiceTest.kt, src/test/java/com/dogGetDrunk/meetjyou/image/cloud/oracle/service/UserImgServiceTest.kt
