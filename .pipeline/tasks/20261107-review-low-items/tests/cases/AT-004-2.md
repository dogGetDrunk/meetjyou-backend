# AT-004-2: NotificationDispatcher — 결과 기록 실패가 같은 배치를 끊지 않음

- 요구사항: REQ-004
- Given: 기존 `NotificationDispatcherTest`처럼 mockk로 조립한 `NotificationDispatcher`(claim은 `TransactionTemplate` stub이 바로 실행)
- When:
  - 케이스 A: 배치 3건(attempts 0) — 1번은 `sender.send`가 예외, 그 뒤 1번 `recordRetry`의 `updateResult`(id = 1번)도 예외. 2번은 무효 토큰(`tokenInvalid`) 결과 1개 + 정상 토큰 1개, 3번은 정상 전송
  - 케이스 B: 배치 3건 — 1번은 attempts가 시도 한도(5) 이상이라 `exhausted`, 그 DEAD 기록 `updateResult`가 예외. 2·3번은 정상 전송
  - 케이스 C: 기존 정상 경로(3건 전부 성공)
- Then:
  - A: `dispatchBatch`가 예외를 던지지 않음, 2·3번 `updateResult`(SENT) 각각 호출, `deactivateAllByIdIn`에 2번의 무효 토큰 id 포함해 1회 호출
  - B: 예외 미전파, 2·3번 전송·`updateResult`(SENT) 호출
  - C: 기존과 같은 기록 (동작 유지)
- 작성자: 보조 설계
- 코드 작성자: 별도 test-writer 세션
- 기준 실행: red
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/notification/dispatcher/NotificationDispatcherRecordFailureTest.kt`

## 회귀·증거
