# AT-002-1: JwtProvider.getUserUuid — 클레임 형식 오류·누락은 InvalidJwtException, getExpiration 부재

- 요구사항: REQ-002
- Given: test 설정과 같은 secret으로 만든 실제 `JwtProvider`, 같은 키(HS256)로 직접 서명한 access 토큰 3종 — `userUuid` = `"not-a-uuid"` / `userUuid` 클레임 없음 / 정상 UUID(`generateAccessToken`)
- When: 각 토큰으로 `getUserUuid` 호출, `JwtProvider::class.java.methods`·`declaredMethods` 조회
- Then:
  - `"not-a-uuid"`·누락 → `InvalidJwtException` (`errorCode` = `INVALID_JWT`), `IllegalArgumentException` 아님
  - 정상 토큰 → 발급에 쓴 UUID 그대로 (동작 유지)
  - 이름이 `getExpiration`인 메서드 없음 (리플렉션, C-r1-03)
- 작성자: 보조 설계
- 코드 작성자: 별도 test-writer 세션
- 기준 실행: red
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/auth/jwt/JwtProviderUserUuidClaimTest.kt`

## 회귀·증거

- base RED: 형식 오류·누락(현재 `IllegalArgumentException`), `getExpiration` 존재. 정상 토큰은 동작 유지
- `getExpiration`을 직접 호출하지 말 것(리플렉션만) — 삭제 후에도 컴파일
