- Given: `@SpringBootTest`(test 프로필, 실제 Security 필터 체인; MockMvc 또는 RANDOM_PORT), 외부 의존 `@MockBean`(기존 `AuthSecurityReproIntegrationTest` 패턴). NORMAL 유저 1명·탈퇴(DELETED) 유저 1명, 공지 1건, 플랫폼 `IOS`·`ANDROID` 출시 버전 각 1건. 토큰 5종: 만료 access(`generateAccessToken(uuid, role, -1000)` 등) / 다른 키로 서명한 access / 형식 오류 문자열(`not.a.jwt`) / 탈퇴 유저의 유효 access / NORMAL 유저의 refresh 토큰

  - `GET /api/v1/ios/versions/check?...`, `GET /api/v1/android/versions/check?...`
