# AT-002-2: userUuid 형식 오류 토큰으로 비공개 API → 401 INVALID_JWT

- 요구사항: REQ-002
- Given: `@SpringBootTest`(test 프로필, 실제 필터 체인), `jwt.secret-key`로 직접 서명한 access 토큰(`token_type` = access, 만료 미래, `userUuid` = `"not-a-uuid"`), 대조용 정상 access 토큰(NORMAL 유저)
- When: 비공개 `GET /api/v1/users/me/profile`(또는 기존 테스트의 인증 필요 GET)에 각 토큰을 `Authorization: Bearer`로 전송
- Then:
  - 형식 오류 토큰 → 401, 본문 `errorCode` = `INVALID_JWT` (500 아님)
  - 정상 토큰 → 200 (동작 유지)
- 작성자: 보조 설계
- 코드 작성자: 별도 test-writer 세션
- 기준 실행: red
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/auth/MalformedUserUuidClaimIntegrationTest.kt`

## 회귀·증거

- base RED: 필터가 `BusinessException`만 잡아 `IllegalArgumentException`이 500으로 나감
