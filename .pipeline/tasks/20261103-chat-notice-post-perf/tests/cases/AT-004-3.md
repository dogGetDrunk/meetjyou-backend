# AT-004-3: 기발송·삭제 이벤트 INFO skip

- 요구사항: REQ-004
- Given:
  - NoticeBroadcaster·TermsReconsentBroadcaster의 원천 잠금 조회가 정상 원천을 반환
  - 해당 prefix outbox 존재=true, 즉 수동 재발송이 먼저 완료된 상태
  - 별도 공지 삭제 케이스에서 원천 잠금 조회가 없음, 기존 404 예외로 구별 가능
  - 실제 발송 빈에 Repository mocks 주입, 실제 핸들러에 그 발송 빈을 연결; INFO/ERROR 로그·운영 알림 호출 캡처
- When:
  - 공지·약관 각각의 이벤트 핸들러를 반복 실행해 발송 빈 경유 기발송 처리를 확인
  - 별도 공지 삭제 후 이벤트 처리 실행
- Then:
  - 기발송 두 경로 모두 outbox 추가 저장 0건·INFO skip, ERROR 및 운영 알림 0회
  - 삭제된 공지도 INFO skip, API 실패로 전파되는 예외·outbox 쓰기·운영 알림 없음
  - 기발송 예외와 실제 장애 예외의 분기 고정, 단위 테스트 직접 핸들러 호출은 이 skip 케이스에만 허용
- 계약: 발송 빈·Repository·예외·핸들러 시그니처와 테스트 지원 계약(StatementInspector 실패 주입·SQL 계수)은 티켓 T-03 `## 확정 인터페이스` 절을 그대로 따름 — 임의 이름·생성자 금지
- 추가 고정(C-r1-03 커밋 시점 예외): 핸들러 단위 — 발송 빈 mock이 `UnexpectedRollbackException` throw → `on(event)` 비전파 + `sendOperationalAlert` 1회 (공지·약관 각각), `BroadcastAlreadySentException`·`NoticeNotFoundException`/`TermsNotFoundException` → 비전파 + 알림 0회
- 작성자: 보조 설계
- 코드 작성자: 별도 test-writer 세션
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/notification/BroadcastAlreadySentTest.kt`

## 검증 경계·실행

- 종류: 단위·기발송/원천없음 skip
- 실행: `./gradlew test --tests "*BroadcastAlreadySentTest"`
- 전체 완료 증거: `./gradlew test build` + `./gradlew dockerTest`, 또는 spec 검증 절차가 정한 동일 HEAD CI dockerTest 성공 증거
- 보호 코드 원본: 태스크 `tests/code/<위 저장소 상대 경로>`; 이 단계에서는 케이스 문서만 작성, test-writer가 코드 생성
- 코드에 `AT-004-3` 표기, 구현 워커의 보호 파일 수정 금지; skipped·미실행·예상 결과를 통과로 보고하지 않음
