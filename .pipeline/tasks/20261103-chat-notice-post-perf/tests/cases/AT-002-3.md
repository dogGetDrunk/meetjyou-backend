# AT-002-3: 조회수 실제 쓰기 롤백 후 상세 응답 정상

- 요구사항: REQ-002
- Given:
  - 실제 읽기·DTO 변환·PostViewService tx, 테스트 본문 트랜잭션 없음, 초기 views=V
  - 조회수 저장 중 실제 DB 쓰기 flush 이후 tx 종료 전에 실패하도록 테스트 전용 fault injection
  - PostViewService 프록시 자체를 throw mock으로 대체하지 않음; 로그 수집 및 독립 검증 tx 사용
- When:
  - 실제 상세 조회를 실행, 조회수 tx에서 flush된 쓰기 뒤 예외 발생·실제 rollback 유도
  - 응답 후 새 tx에서 post views 및 조회 로그 확인
- Then:
  - 상세 응답 정상, 응답 views=V, 필요한 DTO 연관 필드 정상
  - post views=V, 조회 기록은 호출 전 상태로 실제 rollback, WARN 로그 존재
  - 읽기 tx 종료 뒤 증가 호출이어서 rollback-only/UnexpectedRollbackException이 상세 응답으로 전파되지 않음
- 이 단계 완료 기준(메인 설계 확정): 보호 파일 작성 + AT ID 표기 + 티켓 확정 인터페이스·케이스 Given/When/Then 일치. 대상 클래스가 아직 없고 `tests/code`가 Gradle 소스셋 밖이라 컴파일·RED 실행 불가는 정상이며 실패 사유가 아님 — 컴파일·RED·GREEN은 구현 워커 gate에서 확인. 기존 초안이 있으면 검토·보완 후 succeeded로 보고
