# AT-001-1: 채팅 unread 집계 Repository 고정 호출

- 요구사항: REQ-001
- Given:
  - 요청자 JOINED 멤버십으로 목록에 나오는 방 0개·1개·10개의 독립 fixture
  - cursor 있음/없음이 섞인 목록, 집계 projection이 없는 빈 방 포함
  - ChatMessageRepository mock, 실제 ChatReadService의 목록 경유 buildUnreadCountMap 실행 가능한 단위 구성
- When:
  - 각 목록 fixture에서 실제 unread map 생성 경로 1회 실행
  - 각 실행별 mock 호출 기록 초기화, roomUuids와 requesterUuid 캡처
- Then:
  - 방 0개: 새 집계 메서드 호출 0회; 방 1개·10개: countUnreadByRoomUuids 호출 각각 정확히 1회
  - 전달 roomUuids는 목록 방 전체, requesterUuid는 현재 요청자; 방별 구 count 메서드 사용 없음(메서드 삭제 시 검증 대상도 제거)
  - projection 값의 방별 연결과 빈 방 0 처리 확인; 이전 루프가 방 수만큼 호출되는 구현은 실패
- 작성자: 보조 설계
- 코드 작성자: 별도 test-writer 세션
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/chat/ChatUnreadAggregationTest.kt`
