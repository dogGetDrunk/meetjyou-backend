# AT-002-2: 게시글·플랜 API 키 길이와 재시도

- 요구사항: REQ-002
- Given: 실제 게시글·플랜 생성 API·서비스·DB 및 유효 인증·요청, 각 요청 전 리소스·생성 연관 행·키 행 건수; 정확한 게시글 API URL과 fixture는 보완된 참조로 확인
- When: 각 API에 256자 키 전송; 별도 255자 키로 최초 생성 후 동일 키·동일 body 재요청; null 키도 대조
- Then: 256자는 400 INVALID_INPUT_VALUE·404 아님, 리소스·키 행 증가 0 및 부분 생성 없음; 255자 최초 200(기존 응답 코드), 재요청은 같은 리소스 UUID이며 중복 저장 없음; null 키는 정상 생성·멱등 키 행 미생성
- 작성자: 보조 설계
- 코드 작성자: 별도 test-writer 세션
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/common/idempotency/IdempotencyKeyLengthIntegrationTest.kt`
