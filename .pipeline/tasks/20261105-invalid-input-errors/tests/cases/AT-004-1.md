# AT-004-1: Apple 디코더 서명 우선·누락 클레임

- 요구사항: REQ-004
- Given: 실제 AppleJwtDecoder, 테스트 RSA 키와 메모리 JWKSetSource 기반 AppleJwksCache.create(origin = ..., ...); 신뢰 키/다른 서명 키 구분, exp는 충분한 과거/미래; 외부 네트워크 없음
