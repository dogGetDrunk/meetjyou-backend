# AT-002-1: 정원과 joined 경계값 허용

- 요구사항: REQ-002
- Given:
  - H 작성 PLANNING/OPEN 파티, joined=3, Post.capacity=Party.capacity=5
- When:
  - H가 capacity=3으로 updatePost 호출·커밋; title=`Boundary accepted`, 다른 값은 유효값
- Then:
  - capacity == joined이므로 예외 없이 성공
  - Post.capacity=Party.capacity=3, party.joined=3, title=`Boundary accepted` 영속화
- 작성자: 보조 설계
- 코드 작성자: 별도 세션의 Terra
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/post/UpdatePostPartySyncServiceTest.kt`
  - `src/test/java/com/dogGetDrunk/meetjyou/post/PostPartySyncIntegrationTest.kt`
- 테스트 종류: 단위 Kotest BehaviorSpec + H2 통합

## 구현·검증 지침
- 비교 연산자를 <=로 잘못 구현하면 실패하는 경계값 검증
- `./gradlew test --tests '*UpdatePostPartySyncServiceTest' --tests '*PostPartySyncIntegrationTest'`
