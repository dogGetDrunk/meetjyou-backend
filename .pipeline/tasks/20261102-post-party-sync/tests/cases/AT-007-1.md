# AT-007-1: 계획서 detach·삭제 호출 순서

- 요구사항: REQ-007
- Given:
  - H 소유 plan P0에 Party·Post 각 1개 연결, marker 2개, isPlanPublic=true
  - PlanServiceTest의 currentUserProvider.uuid=H.uuid, detachPlan 각 반환값=1
- When:
  - H가 PlanService.deletePlan(P0.uuid) 호출
- Then:
  - verifyOrder: partyRepository.detachPlan(P0) → postRepository.detachPlan(P0) → markerRepository.deleteAllByPlan(P0) → planRepository.delete(P0)
  - 각 단계 1회 호출, post-first 순서면 실패
  - bulk detach 유지, snapshot 엔티티를 load-and-null하는 경로 추가 없음, 타인 plan 삭제 거부 기존 테스트 유지
- 작성자: 보조 설계
- 코드 작성자: 별도 세션의 Terra
- 보호 대상 테스트 파일:
