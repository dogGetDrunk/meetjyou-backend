# AT-003-2: 모집 재개와 신청 허용·멱등성

- 요구사항: REQ-003
- Given:
  - H 작성 Post.status=RECRUITMENT_COMPLETED, Party.recruitmentStatus=CLOSED, progressStatus=PLANNING, joined=1/capacity=4
  - 사용자 U는 해당 파티 membership 없음
- When:
  - H가 updatePostStatus(RECRUITING) 커밋 후 동일 요청을 1회 더 커밋
  - U가 requestJoinParty(partyUuid, "Reopened") 호출·커밋
- Then:
  - 재개 요청 두 번 모두 성공, Post=RECRUITING/Party=OPEN
  - U 신규 신청 성공, PENDING 1건, joined=1 유지
- 작성자: 보조 설계
- 코드 작성자: 별도 세션의 Terra
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/post/UpdatePostStatusServiceTest.kt`
  - `src/test/java/com/dogGetDrunk/meetjyou/post/PostPartySyncIntegrationTest.kt`
- 테스트 종류: 단위 Kotest BehaviorSpec + H2 통합

## 구현·검증 지침
- D4의 대칭 OPEN 전환 확인, 정원 충족 여부는 이 케이스에서 변경하지 않음
- `./gradlew test --tests '*UpdatePostStatusServiceTest' --tests '*PostPartySyncIntegrationTest'`
