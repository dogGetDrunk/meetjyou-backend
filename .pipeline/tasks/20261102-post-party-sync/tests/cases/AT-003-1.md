# AT-003-1: 모집 완료와 신규 신청 차단·멱등성

- 요구사항: REQ-003
- Given:
  - H 작성 Post.status=RECRUITING, party.progressStatus=PLANNING/recruitmentStatus=OPEN, joined=1/capacity=4
  - 사용자 U는 해당 파티 membership 없음
- When:
  - H가 updatePostStatus(RECRUITMENT_COMPLETED)를 커밋하고 같은 요청을 1회 더 커밋
  - U가 requestJoinParty 호출
- Then:
  - 상태 변경 두 번 모두 성공, Post.status=RECRUITMENT_COMPLETED/Party.recruitmentStatus=CLOSED
  - U 신청은 PartyRecruitmentClosedException, 기존 PARTY_RECRUITMENT_CLOSED/409, 신규 PENDING 미생성
  - 각 status 호출에서 lockPartyOfPost → lockByUuid 순서
- 작성자: 보조 설계
- 코드 작성자: 별도 세션의 Terra
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/post/UpdatePostStatusServiceTest.kt`
  - `src/test/java/com/dogGetDrunk/meetjyou/post/PostPartySyncIntegrationTest.kt`
- 테스트 종류: 단위 Kotest BehaviorSpec + H2 통합

## 구현·검증 지침
- UpdatePostStatusTest의 요청 enum 유효성 검증도 유지
- `./gradlew test --tests '*UpdatePostStatusServiceTest' --tests '*UpdatePostStatusTest' --tests '*PostPartySyncIntegrationTest'`
