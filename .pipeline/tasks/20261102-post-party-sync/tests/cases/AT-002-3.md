# AT-002-3: 변경 전 검증과 409 오류 계약

- 요구사항: REQ-002
- Given:
  - H 작성 파티 joined=3/capacity=5, 기존 plan=P0·compPreference=C0
  - 요청 capacity=2와 존재하지 않는 planUuid=`00000000-0000-0000-0000-000000000099`, title=`Must not apply`, 새 companionSpec
- When:
  - H가 updatePost 요청; 별도로 ErrorCodeStatusTest 전체 코드 상태 표 실행
- Then:
  - plan 조회 오류보다 PartyCapacityBelowJoinedException이 먼저 발생
  - verifyOrder: 파티 락 → Post lockByUuid → 작성자·COMPLETED 확인 → 정원 검증; planRepository 조회·compPreference 삭제/저장 호출 0회
  - Post/Party 필드와 plan·compPreference 그대로; ErrorCode.PARTY_CAPACITY_BELOW_JOINED.status=HttpStatus.CONFLICT
  - 메시지 `Capacity cannot be lower than the current member count`, 예외에 partyUuid·capacity=2·joined=3 정보, HTTP 응답 409 및 해당 code 확인
  - ErrorCodeStatusTest의 EXPECTED_STATUS에 신규 code 존재 및 전체 code 누락 없음
- 작성자: 보조 설계
- 코드 작성자: 별도 세션의 Terra
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/post/UpdatePostPartySyncServiceTest.kt`
  - `src/test/java/com/dogGetDrunk/meetjyou/post/PostPartySyncIntegrationTest.kt`
  - `src/test/java/com/dogGetDrunk/meetjyou/common/exception/ErrorCodeStatusTest.kt`
- 테스트 종류: 단위 Kotest BehaviorSpec + H2 HTTP 통합
