# AT-001-2: 증원 후 신청·승인 성공

- 요구사항: REQ-001
- Given:
  - H 포함 JOINED 3명, PLANNING/OPEN, Post·Party capacity=3, 아직 신청하지 않은 사용자 U
  - H가 capacity=10으로 updatePost를 커밋한 상태
- When:
  - U가 `requestJoinParty(partyUuid, "Jeju trip")` 실행·커밋
  - H가 U의 PENDING을 `approveJoinRequest(partyUuid, U.uuid)`로 승인·커밋
- Then:
  - 신청과 승인 모두 PARTY_FULL 없이 성공
  - 별도 트랜잭션에서 U의 memberStatus=JOINED, party.joined=4, Post.capacity=Party.capacity=10
- 작성자: 보조 설계
- 코드 작성자: 별도 세션의 Terra
- 보호 대상 테스트 파일:
  - `src/test/java/com/dogGetDrunk/meetjyou/post/UpdatePostPartySyncServiceTest.kt`
  - `src/test/java/com/dogGetDrunk/meetjyou/post/PostPartySyncIntegrationTest.kt`
- 테스트 종류: 단위 Kotest BehaviorSpec + H2 통합(SpringExtension)

## 구현·검증 지침
- RequestJoinPartyTest / ApproveJoinRequestTest의 HOST·신청자 준비 패턴 참고, 실제 서비스 간 연동은 H2에서 검증
- 기존 신청/승인 production 로직 변경 금지
- `./gradlew test --tests '*PostPartySyncIntegrationTest' --tests '*RequestJoinPartyTest' --tests '*ApproveJoinRequestTest'`
